# 睡眠タイプ予報

睡眠の記録(睡眠時間・タイプの割合)をつけて、平均や傾向を見るためのツールです。

## 作った理由

ポケモンスリープのハロウィンイベントで、推しのムウマが【闇鍋】の週だったのに、うとうとを引けず、なかなか会えませんでした。私はこれを勝手に「ハロウィンの悪夢」と呼んでいます。(イベント自体はとても楽しかったです。運営のみなさん、ありがとうございました!)

【闇鍋】の週でも、睡眠タイプで出会いやすさは大きく変わります。「狙う週に、狙うタイプを出したい」と思い、睡眠タイプを記録して管理するために、このツールを作りました。

- 公開ページ: https://mgh2-ume91.github.io/sleep-type-tool/
- 制作者: ゆめくい(X: [@youmay91](https://x.com/youmay91))
- ポケモンスリープ向けの非公式ファンツールです。ゲームの開発・運営会社とは関係ありません。ゲームのロゴ・画像は使っていません。
- 睡眠の記録や読み込んだ画像は、使っている端末のブラウザ(localStorage)の中だけで扱います。サーバーには送信しません。
- 「今夜の寝具」は、画面を開いたときと「表示」を押したときだけ通信します。入れた郵便番号を [zipcloud](https://zipcloud.ibsnet.co.jp/) に、そこで分かった住所を国土地理院の住所検索に、住所から分かった緯度経度(小数2桁に丸めたもの)を [Open-Meteo](https://open-meteo.com/) に送って天気を取ります。郵便番号の代わりに地名で探したときは、入れた地名だけを国土地理院に送ります。昨夜の実測は気象庁のアメダス(出典:気象庁ホームページ。体感温度の計算など加工して作成)から取ります。最寄りの観測地点は端末の中で選ぶので、気象庁へ位置や郵便番号は送りません。通信先はページの Content-Security-Policy で上の4つ(と同じ配信元)だけに限っています(睡眠の記録は送りません)。郵便番号・寝る・起きる時刻と、最後に取得した結果(住所と天気の数値)は端末の中だけに保存し、バックアップのJSONには含みません(全削除で消えます)。同じ日に開き直したときは保存した結果を出して通信せず、日付が変わったあとに開いたとき、または「表示」「更新」を押したときに取り直します。ホームの「昨夜のふりかえり」は、場所を登録してあるときだけ、昨夜と前の晩の気温(気象庁アメダスの1時間ごとの値)を取って端末に保存し、比べます。送り先は気象庁だけで、送るのは観測地点の番号と日付です。値がそろった晩は取り直さず、保存は端末の中だけ(バックアップのJSONには含まず、全削除で消えます)。天気のデータは Weather data by Open-Meteo.com(CC BY 4.0)です。
- 画像の文字読み取りには [Tesseract.js](https://github.com/naptha/tesseract.js)(Apache License 2.0)を同梱して使っています(`vendor/`)。

## 今夜の寝具:気温のしきい値とエアコンの目安

- 「気温のしきい値」(寒くて起きる気温・暑くて起きる気温。初めは 10℃・25℃。エアコンを入れるタイミングは、下回る2時間前で固定です。`TH_DEFAULT.lead`)を端末の localStorage に保存します。バックアップのJSONには入らず、全削除で消えます。
- 寝る〜起きる時刻の時間別の予報気温(体感ではなく気温)で判定します。寒い側は「最初からON」「下回る時刻の2時間前にONタイマー(寝る時刻より前になるなら寝るときにON)」「勧めない」。暑い側は、しきい値を超えると「寝具を薄めに/冷房を検討」。最低(最高)気温がしきい値の±0.5℃(`AC_BORDER_C`)以内なら「微妙。タイマー付きがおすすめ」。
- 昨夜との体感の差で毛布を増減する目安は、これとは別に今までどおり動きます。
