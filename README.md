# 睡眠タイプ予報

睡眠の記録(睡眠時間・タイプの割合)をつけて、平均や傾向を見るためのツールです。

## 作った理由

ポケモンスリープのハロウィンイベントで、推しのムウマが【闇鍋】の週だったのに、うとうとを引けず、なかなか会えませんでした。私はこれを勝手に「ハロウィンの悪夢」と呼んでいます。(イベント自体はとても楽しかったです。運営のみなさん、ありがとうございました!)

【闇鍋】の週でも、睡眠タイプで出会いやすさは大きく変わります。「狙う週に、狙うタイプを出したい」と思い、睡眠タイプを記録して管理するために、このツールを作りました。

- 公開ページ: https://mgh2-ume91.github.io/sleep-type-tool/
- 制作者: ゆめくい(X: [@youmay91](https://x.com/youmay91))
- ポケモンスリープ向けの非公式ファンツールです。ゲームの開発・運営会社とは関係ありません。ゲームのロゴ・画像は使っていません。
- 記録や読み込んだ画像は、使っている端末のブラウザ(localStorage)の中だけで扱います。サーバーには送信しません。
- 画像の文字読み取りには [Tesseract.js](https://github.com/naptha/tesseract.js)(Apache License 2.0)を同梱して使っています(`vendor/`)。
